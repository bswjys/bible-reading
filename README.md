# 📖 성경 통독

1년 동안 성경 66권 1,189장을 **1독·2독·3독** 중 골라 읽는 개인용 통독 PWA입니다.
아이폰 사파리에서 열고 홈 화면에 추가하면 주소창 없는 앱처럼 쓸 수 있고, 인터넷이 없어도 열립니다.

**앱 주소:** https://bswjys.github.io/bible-reading/
(GitHub Pages를 켜면 위 주소에서 열려요 — 아래 **배포** 참고)

## 주요 기능

- **1~3독 선택** — 1독 1,189장 · 2독 2,378장 · 3독 3,567장을 365일(기본)에 자동 배분
- **읽기 방식 2가지**
  - `순서대로 읽기` — 창세기부터 요한계시록까지
  - `섞어 읽기` — 매일 구약 + 신약 또는 시편·잠언이 함께 나오도록 배분
- **장별 체크** — 오늘 분량의 장을 하나씩 톡톡 눌러 체크, `오늘 분량 전체 완료` 버튼도 제공
- **읽기표** — 66권 전체의 장별 현황을 한눈에 보고 바로 체크/해제
- **캘린더** — 날짜별 완료·밀림·예정을 보고 그날 분량을 바로 체크
- **오늘부터 다시 맞추기** — 밀린 장이 있으면 오늘부터 종료일까지 남은 날에 고르게 다시 배분, `원래 일정으로 되돌리기` 가능
- **갓피플 성경 열기** — 오늘 카드에서 [갓피플성경](https://apps.apple.com/kr/app/id511852665) 앱으로 바로 이동
- **백업/복원** — 체크 기록과 설정을 JSON 파일로 내보내고 불러오기
- **PWA** — 홈 화면 아이콘, 오프라인 캐시, 아이폰 상태바 대응

## 아이폰에 설치하기

1. 사파리에서 https://bswjys.github.io/bible-reading/ 열기
2. 하단 **공유** 버튼(□↑) → **홈 화면에 추가**
3. 이름이 `성경 통독`인지 확인하고 **추가**

기록은 이 아이폰 브라우저의 저장 공간에 남습니다. 기기를 바꾸기 전에 **더보기 → JSON 내보내기**로 백업하세요.

## 처음 쓰는 순서

1. **더보기**에서 회독 수(1~3독), 읽기 방식, 시작일, 기간(365/270/180/90일)을 고릅니다.
2. **오늘** 탭에서 오늘 읽을 장을 확인하고, 읽은 장을 눌러 체크합니다.
3. 밀린 날이 생기면 빨간 카드의 **오늘부터 다시 맞추기**를 누릅니다.
4. 본문은 **📖 갓피플 성경 열기**로 이동해 읽고, 진도는 이 앱에서 체크합니다.

## 저장 방식

| 항목 | localStorage 키 | 내용 |
| --- | --- | --- |
| 장별 읽은 횟수 | `book-chap-pass` | `{"1-1": 2}` → 창세기 1장을 2회 읽음 (권번호-장) |
| 설정 | `bible-reading-settings` | 회독 수, 읽기 방식, 시작일, 기간 |
| 다시 맞추기 | `bible-rebalance` | 다시 배분한 날짜별 분량 |

장 기록은 **장 단위**로 남기 때문에 읽기 방식이나 회독 수를 바꿔도 이미 읽은 장이 유지됩니다.
예를 들어 3독으로 읽다가 1독으로 바꾸면, 한 번이라도 읽은 장은 그대로 읽은 장으로 표시됩니다.

## 배포 (GitHub Pages)

이 저장소의 `main` 브랜치 루트가 그대로 배포됩니다.

1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch**, Branch: `main`, Folder: `/ (root)` 선택
3. 1~2분 뒤 https://bswjys.github.io/bible-reading/ 접속

정적 파일만으로 동작하며 빌드 단계가 없습니다. `.nojekyll`이 포함되어 있어 Jekyll 처리를 건너뜁니다.
